## How to read this file / platform limits found during the pull

- **Overview page is locked to "Last 28 days" (currently Oct 1 – Oct 28).** Its date picker is disabled, so for any other window the numbers come from Insights → Results, Content → Overview, Audience → Trends and Messaging, all of which accept a custom range.
- **Benchmarking is also locked to the current last 28 days (Oct 1 – Oct 28).** It can't be set to an earlier window.
- **Lifetime followers is only shown as of today.** The Audience page has no as-of-date control, so it can't give the total at an earlier window end.
- **Reach:** Meta has replaced Reach with **Viewers** in Business Suite (banner: "Facebook reach will no longer be available starting October 31, 2026"). The window-level unique count below is Viewers. A per-post Reach column still exists in the Content table and is reported there.
- **Results-page totals over 1,000 are rounded by Meta** (for example "9.9K"). Exact totals come from the Content → Overview breakdown panel and are shown wherever available.
- **Daily Viewers are not additive.** Meta de-duplicates unique viewers across days, so the daily column does not sum to the window's Viewers total.
- **Per-post metrics are lifetime-to-date, not limited to the window.** The same post shows identical values whichever window is selected (for example, the Oct 8 post showed 2,336 views in both the Sep 17 – Oct 14 and Oct 1 – Oct 28 windows), so post rows reflect totals as of Oct 29.
- **Negative feedback** isn't shown anywhere in current Business Suite Insights for this Page.
