## Data notes and NOT AVAILABLE

- **Date-range method.** Every window was set with Duda's custom date picker. I confirmed each one against the range label and the request Duda sent. I did not use the 7-day and 14-day preset buttons for engagement because they are off by one day: they label calls and forms one day later than the traffic charts (Oct 16–29 instead of Oct 15–28), and the lead totals don't match.
- **Weekly chart buckets are unreliable.** On 30-day ranges, Duda's weekly buckets change depending on the start date. For example, the week starting Sep 29 shows 492 in one range and 602 in another. Use the daily table above, which adds up to the totals.
- **Tooltip wording.** On a 16-day custom range the trend tooltip says "Compared to previous 14 days". The math on 14-day and 7-day windows shows Duda compares against the preceding period of the same length.
- **Total leads** = Click to call + Form submissions for every window.
- **Blog row (⚑).** Duda's breakdown donut calls the second-largest page `d1-internal-blog-post`. The table shows the same count under one post slug (`what-are-examples-of-class-1-drugs`). The slug changes between snapshots while the count matches, so this row is probably the blog-post template's combined views, not one post. Check before reporting it as a single article.
- **Per-form totals: NOT AVAILABLE (not range-scoped).** The Form Submissions chart has a per-form dropdown (Contact page, For Patients page, For Providers page). Its "Total" (918 / 165 / 42) stayed the same across every date range, and the chart did not change, so it isn't tied to the window. Only the combined form count is recorded.
- **AI visibility score: NOT AVAILABLE.** Highlights shows 72% (+11%) for every date range, and the competitor and prompt panels show sample brands (Northwind Traders, Contoso, and so on) behind an "Unlock your AI Visibility access" upsell. Treat it as placeholder data.
- **Unique users** can't be added across windows; each value is Duda's de-duplicated count for that window.
- **Not pulled:** device-type split (desktop / tablet / mobile filter toggles), state or city geography (the Geolocation table shows countries), and search keywords or referrer domains (not shown on these pages).
- **Current site issues (as of pull date, not historical):** Google Business Profile not connected; 9 images without alt text; 27 blog posts missing meta tags.
- **Time zone:** Duda doesn't say which time zone it uses to count days in this view.
